name: Toujours utiliser les accents français
description: Ne jamais écrire de texte français sans accents (été, pas ete) dans le code, les templates, les strings user-facing
type: feedback
---

Toujours écrire le français avec les accents corrects dans les strings user-facing (emails, UI, messages d'erreur).

**Why:** L'utilisateur a corrigé "ete" → "été". Les textes sans accents font non-professionnel.

**How to apply:** Dans tout contenu visible par l'utilisateur (emails, labels, messages, toasts), utiliser les accents : é, è, ê, à, ù, ç, etc. Ne jamais écrire en français "simplifié" sans accents.
